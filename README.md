## 🚀 What this project does

AssureFi is a full-stack AI-powered platform for DeFi security analysis. It combines smart contract auditing, liquidity monitoring, risk scoring, portfolio tracking, and sentiment analysis into one experience for crypto investors.

This repository is best positioned as:
- a real-world full-stack AI product
- a multi-service application with frontend + backend + external API integrations
- a strong showcase for product thinking, system design, and AI integration

---

## ✨ Core features

| Feature | What it does |
|---------|--------------|
| 🔍 Smart Contract Audit | Uses AI to analyze contract behavior, identify vulnerabilities, and highlight risk areas. |
| 📊 Liquidity & Risk Monitor | Tracks liquidity, trading patterns, and potential exit-scam signals. |
| 💬 Sentiment Analysis | Combines AI with social/news data to reflect market mood. |
| 🔐 Portfolio Shield | Helps users monitor and save important portfolio insights. |
| 🧠 Unified Analysis | Gives a combined view of contract, sentiment, and risk signals in one workflow. |

## 🚀 Quick start

### Prerequisites
- Node.js 18+
- npm
- Git

### Install and run

```bash
git clone https://github.com/pradeepmisal/ASSURIFI_MODIFIED.git
cd ASSURIFI_MODIFIED
npm install
npm run build
```

### Run locally

```bash
npm run dev
```
